# Protocolo de Validação Independente — SHIFT Multi-Regime V5.1

## Versão avaliada

`SHIFT_MULTI_REGIME_V5.1`

## Status

Arquitetura congelada antes da inspeção dos resultados do conjunto de validação.

## Objetivo

Avaliar o desempenho do SHIFT Multi-Regime V5.1 em dados epidemiológicos não utilizados para ajuste da arquitetura multi-regime.

## Conjunto principal de validação

Ano: 2023

Unidade espacial:

27 unidades federativas brasileiras.

Fonte:

SIVEP-Gripe / INFLUD23.

## Regra temporal

A análise deve ser executada de forma pseudo-prospectiva.

Para cada UF, o algoritmo deverá ser executado utilizando somente os dados disponíveis até cada semana epidemiológica avaliada.

Nenhuma informação de semanas futuras poderá ser utilizada para determinar quando um alerta teria sido emitido.

## Algoritmo congelado

- Bernoulli LLR da V4;
- segmentação recursiva;
- min_weeks_each_side = 3;
- thresholds P99 condicionados ao comprimento do segmento;
- direção determinada pela diferença entre positividade à direita e à esquerda;
- nenhuma retunagem durante a validação.

## Avaliação

As previsões produzidas pelo algoritmo serão congeladas antes da consulta às referências epidemiológicas externas.

Métricas principais:

1. acurácia direcional;
2. erro temporal absoluto;
3. proporção dentro de ±1, ±2 e ±3 semanas;
4. número de regimes detectados;
5. falsos regimes;
6. desempenho por intensidade do sinal;
7. desempenho por observabilidade.

## Definição de sucesso

A validação não utilizará uma regra retrospectiva de aprovação baseada nos resultados observados.

Os resultados serão reportados integralmente, incluindo falhas, casos não resolvidos e limitações.

## Controle de contaminação

Nenhuma modificação no algoritmo poderá ser realizada após a geração das previsões de 2023.

Qualquer alteração motivada pelos resultados desta validação deverá ser registrada como uma nova versão.
